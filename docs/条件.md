# 条件のしくみ

依頼文から、次の3つの解析のどれを出すかを決める。決め方は4種類ある。結果の数字は [レポート](レポート.md)、テスト文は [テストセット](テストセット.md) にある。

| 呼び方 | 何をするか |
|---|---|
| はんだ亀裂進展 | はんだの亀裂がどこまで進むかを見る |
| はんだ寿命予測 | はんだが何回で寿命になるかを見る |
| 疲労寿命予測 | 金属が繰り返しでいつまで持つかを見る |

モデルを使う条件は Sol、Terra、Luna の3つである。モデルIDは `gpt-5.6-sol-medium`、`gpt-5.6-terra-medium`、`gpt-5.6-luna-medium`。

辞書とオントロジーだけ、教え方を3段階にしている。

| 段階 | 足すこと |
|---|---|
| ①同義語未登録 | カタログにある言い方だけ |
| ②同義語登録 | ソルダ、クラック、クラックグロース |
| ③同義語＋スラング登録 | ②に、割れと持たない |

折れはどの段階にも入れていない。LLM選択とLLM採点は、段階を変えても同じカタログを読む。

## カタログに入っているもの

ファイルは `catalog/tools.yaml`。LLM選択とLLM採点は、この内容をモデルに渡す。ソルダ、クラック、クラックグロース、割れ、持たない、折れは書いていない。

はんだ亀裂進展（`solder_crack_propagation`）。はんだ接合の亀裂が、繰り返しでどこまで進むかを模擬する。

- 別名: はんだ亀裂進展、半田亀裂進展、ハンダ亀裂進展、半田き裂進展、ハンダき裂進展
- 目的の手がかり: 亀裂進展、き裂進展、進展量
- 弱い語（辞書だけが使う）: 亀裂、き裂

はんだ寿命予測（`solder_life_prediction`）。はんだ接合が何回の温度サイクルで寿命に達するかを予測する。

- 別名: はんだ寿命予測、はんだ寿命、はんだの寿命、半田寿命、半田の寿命、ハンダ寿命、ハンダの寿命
- 目的の手がかり: はんだ寿命、半田寿命、ハンダ寿命、熱疲労寿命、寿命に達する
- 弱い語: 寿命

疲労寿命予測（`fatigue_life`）。金属部材の繰り返し荷重に対する疲労寿命を予測する。

- 別名: 疲労寿命予測、疲労寿命、高サイクル疲労
- 目的の手がかり: 疲労寿命、高サイクル疲労、sn、疲労
- 弱い語: 寿命

ほかに、分野、入力、制約、出力、他ツールとの違いもカタログにある。LLMには渡す。辞書の照合では、名称・別名・目的の手がかり・弱い語だけを見る。

## LLM選択（A1、A2、A3）

モデルがカタログと依頼文を読み、候補と質問を自分で返す。追加の辞書は無い。

- 書いていない目的で、一つに決めない。
- どちらとも言えるときは、両方出して質問する。
- 目的が書いてあれば、質問しない。
- どれにも当てはまらなければ、候補を空にして保留する。

## 辞書（B1、B2、B3）

モデルは使わない。登録した語が文の中にあれば当たる。「亀裂進展」のように、語がつながって入っている必要がある。

1. 「会議」「化学分析」のような事務の語があれば、ツールは出さず保留する。
2. 「計算」「見たい」「シミュレーション」のような、解析を頼む語が無ければ保留する。
3. ツール名か目的の手がかりが当たれば、そのツールを出す。2件当たって「両方」と書いていなければ質問する。
4. ツール名も目的も無く、「はんだ」だけ分かれば、亀裂進展と寿命予測を両方出して必ず質問する。
5. 「亀裂」や「寿命」だけなら、当たったツールを出して質問する。

解析を頼む語: 解析、シミュレーション、計算、予測、評価、見たい、見て、知りたい、調べ、実行、回して、回し、出して、出し、求め、やって、やっと、お願い、ちょうだい、したい、やりたい、確認、比較、取って

両方と読む語: 両方、いずれも、それぞれ、続けて、比較、そのあと、ついで

事務として捨てる語: 意味、文献、参考資料、日程、スケジュール、会議、打ち合わせ、メール、フォルダ、写真、目次、報告書、天気、手順、予約、ライセンス、探して、整理して、化学分析、工数、見積、使い方、更新日

段階で増えるのは次だけである。目的の手がかりと弱い語は、カタログのまま変えない。

| 段階 | 組のキーワード | 亀裂進展に足す別名 | はんだ寿命に足す別名 |
|---|---|---|---|
| B1 ① | はんだ、半田、ハンダ | なし | なし |
| B2 ② | 上にソルダ | クラック、クラックグロース | なし |
| B3 ③ | B2 と同じ | 上に割れ | 持たない |

組のキーワードは、目的の語が無いときに使う。「はんだの亀裂進展」のように目的が当たっていれば、組の二つには広げない。

## LLM採点（C1、C2、C3）

モデルは3つのツールに0から100の点を付ける。この点数は確率ではない。どれを出すかは、次の規則が決める。見るカタログはLLM選択と同じで、追加の辞書は無い。

- 50点未満は出さない。全部50点未満なら、候補は空で質問する。
- 50点以上で、1位との差が15点以内のものを残す。
- 2件以上残れば質問する。
- モデルが「情報が足りない」と言っても、1位が75点以上なら、その理由だけでは質問しない。

## オントロジー（D1からD12）

語を概念にして、概念の組み合わせでツールを決める。D1、D5、D9 はプログラムが文字を探す。それ以外は、モデルが概念を選び、ツールの決定は同じ組み合わせが行う。モデルにはカタログを渡さない。

| そろった概念 | 出すツール |
|---|---|
| はんだと亀裂、または亀裂と進展 | はんだ亀裂進展 |
| はんだと寿命、または熱疲労と寿命 | はんだ寿命予測 |
| 疲労と寿命、疲労だけ、S-N だけ | 疲労寿命予測 |
| はんだだけ | 亀裂進展と寿命予測を出して質問 |
| 寿命だけ | はんだ寿命と疲労寿命を出して質問 |

2件以上出て、「両方」と書いていなければ質問する。事務の語と、解析を頼む語は、辞書の①と同じ一覧を使う。

長い語を先に取る。たとえば「熱疲労」があると、その中の「疲労」は別に立たない。

ラベルは次のとおりである。②③は、①に足した語だけを書いた。

| 概念 | ①にある語 | ②で足す | ③で足す |
|---|---|---|---|
| はんだ | はんだ、半田、ハンダ | ソルダ | |
| 亀裂 | 亀裂、き裂 | クラック、クラックグロース | 割れ |
| 進展 | 進展、進む | | |
| 寿命 | 寿命 | | 持たない |
| 熱疲労 | 熱疲労 | | |
| 疲労 | 疲労、高サイクル疲労 | | |
| 金属 | 金属 | | |
| S-N | sn | | |

金属だけではツールに届かない。割れは亀裂、持たないは寿命として登録してある。一つに決めない、とは書いていない。はんだと割れがそろえば亀裂進展の1件、はんだと持たないがそろえばはんだ寿命の1件になる。
